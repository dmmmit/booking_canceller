# Прогнозирование отмены бронирования отелей

Краткое описание: Этот проект представляет собой Telegram-бота, предназначенного для персонала отелей, который прогнозирует вероятность отмены бронирования. Бот использует модель машинного обучения, обученную на данных о прошлых бронированиях, способах оплаты, погодных условиях и других факторах, чтобы предоставить администраторам отелей информацию о вероятности отмены для каждого нового бронирования. Разработанный в рамках хакатона для ПСБ Банка, проект направлен на минимизацию потерь от отмен бронирований в гостиничной индустрии.

---

## Установка и запуск проекта

1. Клонирование репозитория:
      ```git clone [Ссылка на GitHub репозиторий]```
   
2. Установка зависимостей:
     ``` pip install -r requirements.txt ```
   
3. Укажите токен для Телеграмм бота в config.py

4. Запуск проекта: ```python3 bot.py```


---

## Основной функционал проекта

• Получение данных о новом бронировании: Бот получает информацию о новом бронировании (возможно, через интеграцию с системой бронирования отеля).
• Обработка данных: Бот предобрабатывает данные о бронировании и использует модель машинного обучения для прогнозирования вероятности отмены.
• Вычисление вероятности отмены: На основе данных и модели вычисляется вероятность отмены бронирования в процентах.
• Предоставление информации администратору: Администратор получает уведомление в Telegram с информацией о новом бронировании, включая прогноз вероятности отмены. Информация может включать данные о пользователе и другие релевантные факторы.

## Заключение

Этот проект предоставляет ценный инструмент для гостиничного бизнеса, позволяющий минимизировать финансовые потери от отмен бронирований. Удобный Telegram-бот обеспечивает оперативный доступ к прогнозам вероятности отмены, что позволяет персоналу отеля принимать проактивные меры.

Возможные улучшения:

• Интеграция с существующими системами бронирования отелей.
• Использование более сложных моделей машинного обучения.
• Добавление новых признаков для повышения точности прогнозов (например, анализ текста отзывов).
• Разработка более детального отчета об отмене бронирования.
• Адаптация модели под разные типы отелей.
